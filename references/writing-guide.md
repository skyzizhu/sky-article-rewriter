# 写作与案例选择指南

## 让读者一步步理解

识别障碍后再选解释方法，不默认每个术语都需要一个故事。

| 障碍 | 建议处理 |
|---|---|
| 概念陌生 | 日常语言释义 → 正式名称 → 必要时举例 |
| 因果跨度大 | 展开中间变化，区分确定关系与假设条件 |
| 相近概念混淆 | 明确各自含义，指出混淆会影响什么判断 |
| 数据难理解 | 说明口径、基数、时间范围及比较对象；缺失时指出缺失 |
| 缺少背景 | 补充理解本文必要的最少背景，避免旁支长篇介绍 |
| 结论过于概括 | 说明适用条件，以及现有材料无法覆盖的情况 |

允许先给结论建立方向，再展开解释；后续内容应增加机制、依据或边界，避免换句话重复。标题表达本节真正解决的问题，不强制全部写成问句。

口语化不等于故意碎句、过度使用“你想想”“说白了”，也不等于把读者当作儿童。保留术语中有用的精度，用具体语言解释它。

## 相似案例的选择

先用一句话写明需要解释的关系，例如“单次消耗下降，可能刺激使用量增加”。再检查候选案例：

- 主要参与者、变化方向、反馈过程是否能明确对应？
- 读者是否容易理解案例，还是需要先学习另一个复杂领域？
- 差异会不会破坏正在解释的机制？若会，放弃该类比。
- 案例是否比直接解释更有帮助？若没有，直接解释。

优先选择读者熟悉且对应清晰的案例，不按名气选择。同一个案例可解释相邻概念时可以沿用，减少频繁切换场景。

真实案例可以提供历史参照，但不同背景的结果不能直接预测本文情境。需要具体事实才能成立的真实案例，应查证权威或第一手来源，并在对应陈述附近引用。不能把概念模型包装成真实历史故事。

假设情境用于控制变量、解释机制。开头明确“假设”或“举个简化的例子”，数值仅作演示，不能当成实际统计。

## 不同文章的处理重点

- 观点评论：分开主张、论据和价值偏好；不要把作者立场包装成唯一答案。
- 科普说明：先给必要概念，再解释过程；简化后仍保留关键机制。
- 研究解读：分清研究对象、方法、结果与解释；区分相关关系和因果结论，不扩大样本适用范围。
- 新闻与行业分析：保留原文时间点；后续信息如需补充，要说明与原文的时间差，不悄悄改写为最新状态。
- 叙事与人物文章：维护事件顺序、视角与人物处境；主题理解可以有多种，不凭空推断人物动机。

## 支持深入阅读

把篇幅分配给决定结论的环节。例如“某现象是否普遍”取决于样本与口径，就解释证据范围；“为什么出现这个结果”取决于机制，就展开过程和替代解释。

用户要求带读、逐段讲解或确实需要回看时，可以在关键处提醒读者：“理解了这一点，再看原文中……就容易明白。”同时提供可核对的小节名或段落定位。不要虚构原文引句。

用户仅要求基于原文解读时，保留原文时点和主张归属；不要擅自扩展为全面事实核查。新增现实案例或影响结论的外部事实，仍须遵守核实和来源要求。

默认成稿是可独立阅读的文章。原文已提供足够具体的例子时先用原例，不再增加同结构的类比。多次解释同一机制时保留最清楚的一次，后文直接承接；必要来源提示集中处理，不把每一节写成对原文的评论。
