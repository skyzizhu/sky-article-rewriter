# 人物、事件与叙事推进

只处理影响理解的关系，不默认建人物表或文学分析报告；普通段落写法与审稿要求以主文件为准。

## 重排时保留什么

| 要素 | 必须辨明的关系 |
|---|---|
| 时间 | 区分事件发生、人物获知与转述时点；不能把今天听说的事改成今天发生。顺序不明时不补确定先后 |
| 人物 | 首次出现交代必要身份和关系，多人场景消除代词歧义；不把外貌当性格证据 |
| 场景 | 位置变化影响行动时就近交代，不补造日期、地址、天气或对白 |
| 行动与结果 | 保留关键选择、转折及其依据；原文没有成长、高潮或答案时不硬填 |
| 环境与细节 | 保留影响选择、主题或情绪的细节；没有作用的重复渲染压缩 |

有意义的结果或场景可以前置，再补最少背景。多次回忆使读者跟丢时，先内部还原时间线，再合并零散叙述；关键揭示顺序影响理解时仍保留，不为开头给结论破坏它。

每段推进事件或增加读者对处境的理解。无需把每个场景都翻译成道理，也不在每段末尾设问。对白含糊时保留宽的准确转述，不落实为唯一动机。例如“进去吧，里边没人”不能无依据解释成“别让座位空着”。

## 示例：故事已讲清，不再加感悟

虚构原文：小林春天在车站旁开早餐店，想卖方便赶车者带走的食物。朋友阿远帮忙记账。店里每天忙，但收入付不清房租和食材，还没算小林自己的工时。阿远建议算清每份早餐剩多少钱。小林调整菜单，第三个月仍付不清这些支出，于是关店。原文未提供详细账目。

改写：

# 早餐店每天都忙，小林为什么还是关了门？

小林的早餐店开了三个月就关门了。每天早晨都有客人，但收入始终不够支付房租和食材，还没算上他自己的工时。

他原想在车站旁卖方便赶车者带走的早餐，朋友阿远帮忙记账。发现收支问题后，阿远建议先算清每份早餐能留下多少钱。小林调整过菜单，但到第三个月，收入仍付不清这些支出，最终决定关店。

写法说明：结果前置后交代处境、行动和结局即可，不另写一段“忙碌不等于赚钱”的重复点评。没有账目就不推断具体亏损原因；不将阿远改称财务专家，不补人物心理，也不把个案当成所有早餐店的经营规律。
