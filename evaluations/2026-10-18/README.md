# 文章精读重构：九份真实材料的评测与迭代

日期：2026-10-18。基线版本：[8121010](https://github.com/skyzizhu/sky-article-rewriter/tree/8121010)。

## 结论

当前技能已经能在这些材料上保留主要对象、判断及大部分关键限定，并按内容选择写法；没有必要拆成多个技能或新增整套类型模板。但主旨大致正确，并不意味着每句释义和时间关系都正确。本轮确实发现了对白补理由、标题时间暗示、转述时点错置，以及反复展示内部防错检查等问题。

据此对现有条款作窄幅修订，随后完成四份同源重生成与两组片段回归。多个已定位问题得到改善，但仍有个别讲评句和过具体释义。此次证据支持“这些修订有用，继续可用且需核对”，不支持“全类型已经稳定通过”。

## 怎样测试

不是只阅读规则或挑几篇材料做主观打分：每份材料均先读取正文，再使用冻结的基线技能实际生成中文稿，保留产物，最后对照来源评审。三组生成者各自自检，再交叉检查其他组的材料；主评审整合证据后才修改规则。

统一面向没有专业背景的中文成年读者，要求可独立阅读、循序渐进、保留原文核心及重要条件。两篇公版中文作品采用约1000—1600字重构；六份访谈、技术说明、教程和政治随笔采用约400字精简输出；NASA原文很短，不为字数要求添加新生平。

这意味着：精简稿能验证归属、关键概念和压缩取舍，却不能证明默认完整长访谈或长篇教程已经通过。没有将字数限制本身造成的省略全部判为技能错误。

本轮交叉评审不是完全盲评：部分基线文件包含生成者自检。不同评测者没有先读其他组的独立 findings 文件，但可能看到稿件内的自检。回归是已知问题后的定向检查，不是全新盲测。没有无技能对照组，也没有真实读者行为试验，因此不报告读完率、理解率或无依据的总分。

详见[评测方法](methodology.md)及[版本和产物清单](manifest.json)。

## 实际问题怎样进入技能

| 发现 | 证据与影响 | 处理决策 |
|---|---|---|
| 标题暗中改变时间关系 | 《背影》当场已有落泪，标题却写“多年以后才读懂” | 在原有标题核对中加入隐含先后、因果与程度，不新建标题模板 |
| 含糊释义被落实为理由 | “进去吧，里边没人”变为“别让座位空着” | 明确保留未确定范围，可宽泛转述，不自行补理由 |
| 事件与获知时间混淆 | 《故乡》船上听母亲说“前天”的事，成稿排在离家当天之后 | 在原有时间线操作中区分发生、获知、回忆时点 |
| 无必要的反向总结反复出现 | Goodenough的“没说成捷径”、NASA的“没把经历当登月成因”、文学稿的判案式提示 | 防错检查留在内部；自然保留实际归属，不替作者否认从未提出的命题 |
| 关键条件或身份在压缩中变弱 | MDN的304触发条件、NASA收尾的毕业状态 | 忠实性核对覆盖重新概括的开头与结尾，技术压缩保留触发条件 |
| 陌生机构名称串联 | Jobs稿出现NeXT、皮克斯却未交代角色 | 将已有“首次出场交代身份”延伸至重要机构，仍须依据原文 |
| 文学解释抢过场景与意象 | 《背影》《故乡》末段出现额外主题解释 | 在原有删减动作里试删概括，场景足够时保留余味 |

这些主要是已有要求过于笼统或执行遗漏，故直接修改原条款及必要示例，不增加新技能或新流程模块。

没有因短稿目录化就规定“采访只能有一个主题”；没有因为小说路由未单列就宣称本次把小说当纪实；也没有为了降低讲评感删除所有限定。List的原子经济性与整体环保区别、MDN缓存指令区别、Git作用域和版本条件都应继续保留。

### 两组片段回归与静态核对

- [MDN片段](reviews/technical-regression-mdn.md)：补齐过期副本发条件请求核验、未变返回304与已变返回新内容的关系。只验证相关句子，未将其计为整篇重跑。
- [Jobs/List片段](reviews/interviews-regression-jobs-list.md)：补机构角色，并确认List的实际概念边界应保留。未重新生成两篇全文。
- Git只做新版条款下的静态副作用核对，不计作重生成；N3《射象》未重跑，其末尾外加解读仍是已知待编辑项。

原始稿与修订稿都保留实际状态，未先手工清除残余问题再宣称新规则成功。对于已被现有条款覆盖的残余，继续执行原文回查与编辑，不再叠一份同义禁令。

## 下一步应验证什么

当前最缺的不是更多分类规则，而是多人分歧的真实对谈、长访谈在默认篇幅下的完整交付，以及目标读者的实际理解与跳读反馈。后续应优先填这些缺口，再决定是否修改；本轮不将未测项目写成已通过。
